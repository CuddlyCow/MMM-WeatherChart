# MMM-WeatherChart

Ein MagicMirror²-Modul zur Darstellung des aktuellen Wetters und von Wetterdiagrammen.

## Installation

In den MagicMirror-Modulordner wechseln:

```bash
cd ~/MagicMirror/modules

Repository klonen:

git clone https://github.com/CuddlyCow/MMM-WeatherChart.git

In den Modulordner wechseln:

cd MMM-WeatherChart

Abhängigkeiten installieren:

npm install
